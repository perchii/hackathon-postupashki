# Assumptions and limitations

Сюда записываем все принятые допущения и ограничения анализа.

Примеры:

- Правило определения заказа из строк покупок.
- Обработка пакетных покупок.
- Часовой пояс timestamp.
- Правило классификации внутренних / связанных / независимых внешних каналов.
- Отсутствие исторических затрат на размещения.
- Отсутствие user-level marketing touches.
- Временная ассоциация не интерпретируется как причинный эффект.
